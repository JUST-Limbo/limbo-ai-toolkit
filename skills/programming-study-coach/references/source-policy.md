# 教学来源策略

## 何时读取

在规划课程、解释版本相关行为、推荐练习或引用外部资料前读取本文件。

## 来源优先级

按任务选择最接近原始事实的来源，而不是按 Star 数排序：

1. 用户明确指定的教材、课程或团队规范；若内容过时，保留其教学顺序，同时指出与当前实现的差异。
2. 语言规范、官方 API 文档、官方教程、正式发布说明。
3. 由大学、基金会或成熟练习平台维护，且有公开课程结构、测试或维护状态的资料。
4. 高质量技术书籍或维护良好的项目文档。
5. 社区文章、问答和第三方 Skill 仅作为补充线索；关键结论须回到更高等级来源核对。

Star、下载量和活跃用户量只能说明传播或使用规模，不能单独证明教学效果。若引用这些指标，应说明它们能证明什么、不能证明什么。

## 生成路线前的调研

用户要求生成学习路线、长期计划或完整教学大纲时，不要直接依靠模型记忆编排。先查阅并比较与目标相符的公开方案：

- 官方教程、语言规范和版本文档
- 大学公开课程
- 成熟开源课程或练习平台
- 目标框架的官方示例和迁移指南

在教学大纲中记录：参考了哪些方案、吸收了哪些结构、哪些内容因过时或目标不符而舍弃、哪些部分根据学习者背景重新设计。不能简单复制某一方案，也不能只凭 Star 排序。

作为路线结构的主要参考，来源还应至少具备可审计内容，并有可说明的信誉基础，例如官方或知名教育机构维护、长期公开运行、维护者清晰、课程被广泛采用，或有持续维护与完整练习体系。Star 不是教学质量证明，但来源同时缺少维护记录、机构或作者信誉、公开课程结构和可观察采用情况时，不得仅因“开源”而把它作为主要参考；低知名度个人项目最多作为待核对线索。

无法联网或无法取得必要资料时，可以先建立明确标为“暂定”的结构草案，但不能把它表述为已经完成外部调研的正式路线；条件允许后应补查并更新依据。

## Java 默认来源

- 现代 Java 语言与标准 API：优先 `https://dev.java/learn/`、`https://docs.oracle.com/en/java/javase/` 及相应 JDK 发布说明。
- 语言精确定义：使用与目标版本对应的 Java Language Specification。
- 小步练习和自动测试：可使用 Exercism Java Track，但把它视为练习平台，不视为 Java 规范。
- 赫尔辛基大学 Java MOOC 可用于基础练习顺序；该课程已标注为 legacy 且不再维护，因此版本相关知识必须另用当前官方资料核对。

其它语言应建立同样的“官方事实来源 + 结构化课程 + 可运行练习”组合，不要因为本文件列出 Java 就强行套用 Java 路线。

## 教学方法依据

本 Skill 采用的是可检验的教学机制，不把某个 Agent Skill 的流行度当作成效证明：

- 间隔学习与主动回忆的研究综述：`https://doi.org/10.1038/s44159-022-00089-1`
- 面向编程初学者的 worked example 研究：`https://doi.org/10.22369/issn.2153-4136/6/1/1`
- 编程错误示例类型的对照研究：`https://doi.org/10.1016/j.learninstruc.2021.101497`

这些研究支持采用主动回忆、间隔复习、完整示例后独立练习和自我解释，但不能证明本 Skill 本身有效。评价本 Skill 时仍应观察学习者的延迟回忆、独立解题和迁移表现。

## 时效与引用

- 版本、API 状态、工具安装步骤和课程维护状态会变化；能够联网时先查当前官方页面。
- 在笔记的“资料来源”中记录页面标题、URL、访问日期，以及适用的语言或运行时版本。
- 明确区分来源原文、Agent 解释和学习者自己的理解。
- 不大段复制受版权保护的课程内容；用自己的话概括并链接到原始页面。
- 不确定或来源冲突时，直接标注不确定性和待验证项，不用流畅表述掩盖证据缺口。

## 选材检查

采用一个来源前确认：

- 它是否直接覆盖当前知识点和目标版本？
- 是否公开说明作者、维护者、更新时间或维护状态？
- 示例能否在学习者环境中运行或测试？
- 它提供的是规范事实、教学顺序、练习，还是个人经验？
- 是否有更直接的官方来源可以核对关键结论？
