# 控制台日志回传

## 1. Agent 准备代码

确认文字和相邻元素的选择器、目标间距（CSS px）、相邻元素是否为文字。参考 `scripts/measure.js`，生成参数已填好的、可直接执行的异步自执行函数：

- 保留等待资源、几何检查、单行探针测量和异常清理逻辑，不修改业务样式。
- 移除网络上报及 `endpoint`、`session` 校验；不要调用会执行上报的 `TuneInkGap.run()`。
- 用 `console.log(JSON.stringify(report, null, 2))` 输出 JSON，包含页面、设备备注、时间、环境和测量数据；失败时输出错误信息。
- 不输出页面正文、URL 查询参数、Cookie 或存储内容。

## 2. 用户执行并回传

1. 在目标设备打开实际业务页面，保持前台显示。
2. 打开该页面的控制台，粘贴完整代码并执行。
3. 将输出的完整 JSON 发回给 Agent；失败时也回传错误信息。

手机需能访问本机控制台或远程调试；电脑测量不能代替手机结果。

## 3. Agent 处理结果

核对页面、设备与选择器。`status: "ok"` 表示测量成功，按 `SKILL.md` 计算、调整并汇报结果；`status: "error"` 表示失败，先排查再重测。记录可复用的字体、字号、行高和留白估算值，不执行视觉效果校验。
