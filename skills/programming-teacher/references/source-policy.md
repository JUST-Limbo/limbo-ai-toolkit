# 课程调研与资料来源

规划课程路线或核对技术事实时读取。优先查找准确、适配目标版本的中文资料，包括官方中文文档、可信中文文章与专栏、B 站课程；必要时用原始规范或外文资料补充，并提供中文说明。

## 调研课程路线

1. **考察实际目录**：结合用户目标与技术版本，读取公开开源项目的 README、文档目录与示例模块，文章或专栏的章节，以及 B 站课程的简介和选集标题。沿简介追踪相关课程与路线专栏，核对选集分页与分册，直到取得当前规划所需的结构依据。
2. **判断采用范围**：核实作者或维护者的公开背景、原始出处、版本适配和目录完整性，抽查拟采用的关键正文或代码。B 站课程分别核对发布者身份、内容准确性和完结状态，记录实际支持的采用范围。
3. **归纳知识链路**：从目录提取具体知识点、先修关系和顺序，合并重复主题，结合课程目标补齐缺口。知识深度通过正文与示例核实，大纲组织及教材覆盖按 [HTML 教材规范](html-lessons.md#大纲与教材层级) 完成。
4. **说明待查项**：资料访问受限或依据不足时，标明已核实范围与暂定内容，使用可访问的官方资料、公开项目或课程补充，保留影响路线的待查项。

## 为已有课程划重点

用户要求筛选已有课程的学习范围或逐分集划重点时，读取该课程完整的选集或章节目录，按原顺序逐项归类。已有选集留档可作为目录依据；目录缺失或不完整时说明覆盖范围，不凭记忆补齐分集内容。

划分前说明学习目标、已有基础和本课的取舍标准。基础课围绕当前阶段需要掌握的用法与必要概念，项目课围绕可完成的业务主线，研究或面试目标按所需原理深度安排。已有相关经验可以减少重复讲解，但保留跨领域衔接、接口约定与项目运行所需内容。

可采用以下标记，用户已有分类时沿用其约定；每门课开头说明标记在本课中的具体含义：

| 标记 | 含义 |
| --- | --- |
| 要会用 | 当前目标的重点，需要跟做或能够正确使用 |
| 过一遍 | 了解用途、位置与基本思路，需要时能找到资料 |
| 不看 | 当前目标不需要，或已有其他材料覆盖 |
| 后置 | 当前暂不学习，留到后续阶段、专题或面试复盘 |

结果按分集或章节顺序列出“分集／章节、内容、标记、说明”；连续且取舍一致的条目可以合并，标记不同的条目分别列出。跳过内容给出理由，因重复而跳过时指向实际覆盖它的课程或专题章节；后置内容注明回看阶段或触发条件。避免删除项目主线必需的先修环节。

将结果写入用户指定或已有的学习路线文档，同步受影响的课程概览与章节引用，记录目录来源和划分日期。只要求筛选课程时，交付学习范围与依据。

### 模糊内容的定点核实

标题不足以判断实际内容、讲解深度或是否与其他课程重复时，定位到有疑问的分集或章节，检索相关正文、示例代码或字幕中的关键词，再读取命中位置附近的必要片段。每次只核实少数有疑问的条目，不为划重点通读整套字幕；材料访问遵守用户授权及项目规则。

目标分集缺少可用正文或字幕时，可结合前后集的承接关系、同段落已核实内容与章节位置作判断。对影响取舍的结论区分证据强度：

- **直接核实**：目标分集或章节的正文、代码或字幕直接支持判断。
- **旁证**：相关材料间接支持判断，但未直接核实目标内容。
- **推定**：仅依据标题与目录位置暂作判断，仍有待确认。

反馈以结论和必要的短引文为主，保留可定位的分集、章节或时间点，不大段复制字幕。转述时校正语音识别中的技术术语；需要逐字引用时保留原文，并对影响理解的识别错误作简短校注。证据不足以决定学习范围时，注明待核实，不将推定表述为已确认。

## 核对技术事实

API、语法、默认行为、安装步骤和版本差异以目标版本的官方资料为准，来源冲突时回到原始规范核对。同等准确时优先官方中文；使用原文或第三方解释时，提供准确链接与中文说明。

## 记录来源

在课程根目录的 `.learning/resources.md` 简要记录来源链接、采用的目录或章节、适用版本、核对日期、采用理由及必要的待查项。记录范围以支持当前课程判断为准。

HTML 教材在相关知识旁链接具体来源；学生笔记将核实后的知识、必要代码与结论完整写入正文，注明适用条件与验证情况。
