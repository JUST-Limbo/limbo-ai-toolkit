# 课程调研与资料来源

调研课程、整理学习范围或进一步核实具体章节时读取。

## 可用于调研的资料来源

以视频来源（B 站、YouTube 等）为主要调研途径，公开开源项目、可信文章与专栏作为补充。

### 调研策略

| 来源 | 调研策略 |
| --- | --- |
| 视频来源（B 站、YouTube 等） | 查看发布者或频道背景、简介、完整选集或播放列表，核对顺序、分页分册、版本与完结状态，沿简介查找配套课程、代码与资料 |
| 公开开源项目 | 查看 README、文档目录与示例模块，抽查关键代码，判断适用范围与版本 |
| 文章与专栏 | 查看作者背景、原始出处和章节结构，抽查关键正文与示例 |

### 字幕获取

仅在核实具体内容且现有材料不足时获取或读取字幕；常规调研与划重点不默认读取。先明确待核实问题、目标分集与关键词，仅检索并读取命中位置附近的必要片段，避免整集、整套字幕进入上下文。

优先使用平台字幕、课程配套字幕或用户提供的字幕，读取前核对对应视频、分集与语言。

无法获取字幕时说明限制，改用可访问的正文或代码辅助判断，不将标题推断视为内容核实。

## 对调研的汇总材料划重点

根据学习目标、已有基础和当前阶段筛选汇总材料。基础学习侧重必要概念与用法，项目学习侧重完整业务主线，研究或面试侧重所需原理深度。

按原分集或章节顺序列出“分集／章节、内容、档位、说明”。连续且档位相同的条目可合并；跳过内容说明理由及替代材料的位置，后置内容注明回看阶段或触发条件，保留项目主线必需的先修内容。

### 不同的档位含义

用户已有分类时沿用其约定，否则使用以下档位，并说明其在本次学习中的具体含义：

| 档位 | 含义 |
| --- | --- |
| 要会用 | 当前目标的重点，需要跟做或能够正确使用 |
| 过一遍 | 了解用途、位置与基本思路，需要时能找到资料 |
| 不看 | 当前目标不需要，或已有其他材料覆盖 |
| 后置 | 当前暂不学习，留到后续阶段、专题或面试复盘 |

将结果写入用户指定或已有的学习路线文档，同步受影响的课程概览与章节引用。

## 章节核实

内容、深度或重复程度不明确时，定位目标章节，检索正文或代码的相关片段；需要字幕时遵循 [字幕获取](#字幕获取)。材料访问遵守用户授权及项目规则。

结论区分**直接核实**（目标内容支持）、**旁证**（相关材料支持）与**推定**（仅凭标题或目录）；依据不足时注明待核实。

反馈给出结论、章节或时间点，按需附短引文。转述校正字幕识别错误，逐字引用保留原文并简短校注。
