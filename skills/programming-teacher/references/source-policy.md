# 课程调研与资料来源

在规划课程、解释版本相关行为、推荐练习或设计查阅任务时读取。来源清单维护在项目 `.learning/resources.md`，采用结果与课程结构写入大纲。

## 选择来源

根据用途选择最接近原始事实的资料：

1. 用户指定的教材、课程或团队规范；保留其教学顺序，并说明与目标版本的差异。
2. 语言规范、官方 API、官方教程和发布说明，用于核对事实。
3. 大学、基金会或成熟练习平台的公开课程，用于借鉴结构与练习。
4. 高质量技术书籍和维护良好的项目文档，用于补充解释。
5. 社区文章、问答和第三方 Skill，用于发现线索；关键结论回到更直接的来源核对。

评估作者或维护者、更新时间、目标版本、公开课程结构、完整练习和可观察采用情况。路线的主要参考应有可审计内容及可信维护或教学背景。Star、下载量和用户量说明传播规模，教学价值通过内容与学习者表现判断。

同等准确和完整时优先官方中文；中文缺失或滞后时，提供官方原文并用中文说明阅读范围。非官方翻译标明性质，API 签名、默认值和限制以官方资料核对。

## 调研课程路线

生成长期计划或调整阶段时，比较与目标匹配的官方教程、公开课程、练习平台及框架示例，形成“官方事实来源 + 结构化课程 + 可执行练习”的组合。区分来源提供的规范事实、教学顺序、练习和个人经验，再结合学习者基础重组课程。

大纲记录参考方案、采用结构、因版本或目标差异而调整的内容，以及自行设计的部分。无法取得必要资料时，先保存标为“暂定”的路线草案和待查项，条件具备后补查依据。

### B 站培训课程探索

建立长期学习计划或调整阶段时，必须将 B 站相关培训机构的公开视频作为明确的探索方向，按以下流程取得课程结构依据，再与官方资料及其它公开课程比较。候选视频及递归发现的课程、专栏在采用前均按下文「视频权威性与采用判断」核对，不能因来自培训机构就默认具备权威性。视频课程用于借鉴教学结构，技术事实仍按官方资料核对。

1. **检索入口**：围绕学习语言、目标岗位或能力、框架及目标版本，组合“学习路线”“全套教程”“培训机构”等关键词检索 B 站。核对发布账号与机构的关联、课程年份和技术版本，区分机构原发、转载与剪辑；对匹配目标的不同课程方案进行比较，不仅依据搜索排名或播放量选取。
2. **递归追踪**：读取候选视频简介，追踪其中与当前课程有关的视频、合集及学习路线专栏链接；继续读取新页面中的相关链接，直到取得路线及对应课程，或没有新的相关入口。以规范化链接或视频、专栏标识去重，保留“入口 → 简介或专栏 → 路线阶段 → 对应课程”的关联。跳过广告和无关链接；遇到循环、失效链接、访问限制或路线与版本不匹配时记录原因并停止该分支，不将未访问内容写成已核实依据。
3. **提取路线与选集**：获取专栏明确指出的视频学习路线，保留阶段顺序、先修关系及对应视频链接；逐个读取路线关联视频的选集列表或合集目录，记录分 P 编号、原始标题和顺序。核对分页、折叠与不同课程分册，区分单个视频的选集、系列合集和整条学习路线，避免漏项或把同一课程重复计入。未提供明确路线时标注“未找到路线”，可以从目录推导建议顺序，但须注明为教师推断。
4. **辨认完整性**：分别核对视频、系列课程和整条路线的完整性。结合发布者的完结或更新说明、最近更新日期、计划目录与已发布选集的对应关系、最后章节是否覆盖计划终点，将状态记录为“已完结”“更新中”“疑似停更”或“无法确认”，并附判断依据及核对日期。“全套”“完整版”等标题、选集数量或长时间未更新本身不能证明已完结；部分已发布章节不等于完整课程，路线中某个视频完结也不等于整条路线完结。
5. **归纳知识链路**：将路线阶段和选集标题映射到学习章节、知识点、先修依赖及练习目标，合并不同课程中的重复内容，标明顺序差异、版本差异与缺口。标题只能证明目录列出的主题，不能证明讲解深度、内容准确性或未列出的知识已被覆盖；必要时查阅对应章节内容及官方文档，标题推断的关系单独标注。未完结或状态不明课程只用于有证据的已发布范围，不能因其缺少后续章节就判断那些知识不需要学习；缺失部分用其它完整课程或官方资料补齐，尚未核实的部分保留为暂定。
6. **保存调研结果**：在 `.learning/resources.md` 记录检索关键词、入口、简介与专栏链接、路线与视频的关联、原始选集目录、版本、完整性状态及依据、无法访问或未查明的项目。目录较长时可另存到 `.learning/curriculum/` 下的调研文件并从来源清单链接。大纲记录“来源阶段或选集 → 教学单元”的映射、采用与调整理由、自行设计的部分和待补内容，使章节与知识链路可追溯。

无法检索 B 站或无法完整读取简介、专栏、选集时，明确记录访问范围和缺口；搜索摘要仅作为线索，不能替代实际目录。继续使用可访问的官方资料和公开课程形成暂定路线，保留 B 站待查项，条件具备后补查。

### 视频权威性与采用判断

权威性按具体领域、版本和用途判断，分别记录发布者身份是否可信、课程是否适合作为教学结构参考、技术结论是否已核实；不能将账号认证或机构知名度直接等同于内容正确。

- **核实身份与出处**：通过机构或大学官网、技术项目官方渠道到 B 站账号的链接等可核对证据确认发布关系；讲师的相关教学、工程或项目维护经历应有公开依据，自称专家不作为证明。转载视频追溯原作者、原课程和版本，剪辑或无法追溯的内容不作为主要路线依据。账号认证可辅助确认身份，不能单独证明专业能力。
- **检查实际内容**：在拟采用范围内抽查基础概念、核心机制、版本敏感内容及案例或练习对应章节，与官方文档对照，检查解释是否准确、前提和边界是否交代、案例与课程目标是否一致，以及是否有勘误和维护记录。记录实际检查的章节或时间点；只读到简介和选集标题时，仅可评价目录结构，内容权威性标为“未核实”，不得声称已验证整套课程。
- **排除热度与营销替代证据**：播放量、粉丝量、点赞、评论、机构规模、“官方”“就业必学”“全网最全”等宣传不能单独证明权威性；区分语言或框架官方课程与培训机构自己的官方账号。跨课程比较优先使用独立来源，同一机构的多个账号、转载和重复引用不视为独立验证。
- **决定采用范围**：身份可追溯、目录与目标匹配且相关内容抽查有依据的课程，可作为主要教学结构参考；只有目录可访问或部分内容待核实的课程，仅作为候选或补充线索。存在关键事实错误、版本不适用或来源无法追溯时，不采用其受影响部分作为依据，并记录原因。不同来源冲突时回到目标版本的官方资料核对，不按视频数量投票决定。

在 `.learning/resources.md` 为采用的课程或专栏记录身份依据链接、实际抽查范围与结果、权威性判断的适用范围、采用级别（主要参考 / 补充线索 / 不采用）及理由。权威性、版本适配和完结状态分别记录；已完结不代表权威，发布者可信也不代表课程完整或适用于当前版本。

## 记录来源

在 `.learning/resources.md` 保存来源条目，可按主题或用途分组：

| 字段 | 内容 |
| --- | --- |
| 标题与链接 | 具体页面、章节或锚点 |
| 用途 | 规范事实、路线结构、教材、练习或补充经验 |
| 适用版本 | 语言、运行时、框架或工具版本 |
| 访问日期 | 本次核对日期 |
| 采用理由 | 与当前目标的关系、可信依据及局限 |
| 关联材料 | 大纲单元、HTML 课件章节、学习笔记或练习编号 |

HTML 课件、学习笔记与练习在相关知识旁提供具体来源入口。区分来源原意、教师解释与学习者结论，用自己的话概括并保留原始链接。版本、API 状态、安装步骤和课程维护情况在使用前核对；未核对项标明状态、搜索关键词和待确认内容。

## 把资料变成查阅动作

每个连贯教学单元选择少量直接相关资料，说明其用途、必读或备用性质、本轮范围，以及如何通过目录、站内搜索、API 名称或错误关键词定位。

让学习者完成至少一个短查阅动作，例如查找参数含义、默认行为或错误说明，再将依据用于预测、编码或排错。资料摘要帮助理解，原文查阅训练独立获取信息的能力。需要等待查阅结果的课堂节点见 [课堂工作流](learning-workflow.md#围绕课件开展课堂)。
