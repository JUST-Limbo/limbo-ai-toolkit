# HTML 教材规范

## 大纲与页面组织

依据 [课程调研](source-policy.md#调研策略) 和学习目标，按「章 → 节 → 知识点」组织教材：

| 页面 | 职责 | 路径示例（相对教材目录） |
| --- | --- | --- |
| 总览 | 课程目标、章节目录、先修与成果 | `index.html` |
| 章节目录（按需） | 小节、知识点、掌握深度与教材入口 | `01-语言基础/index.html` |
| 教材正文 | 按连贯主题讲解知识，提供案例与问答 | `01-语言基础/01-类型.html` |

标题和文件名可使用中文，英文名称采用 kebab-case；正文页按章节顺序编号，篇幅较少时可直接放在教材目录下。教材覆盖大纲中的必需知识点，未编写内容注明待编写，已完成条目链接到真实页面或章节。

## 教材内容与表述

- 正文包含目标与先修、知识讲解、教学案例、课件问答及相关资料，按主题安排，不机械套用固定章节。
- 只需了解的知识点，在对应标题后标记「（了解即可）」，如 `反射（了解即可）`；目录中的标题同步保留该标记。
- 采用客观的教材口吻，交代必要背景，使概念、案例与结论可独立理解。案例讲解按 [案例代码讲解](markdown-notes.md#案例代码讲解) 处理。
- 目标为「会用」及以上时提供完整示例，注明所属项目或独立示例范围、必要依赖、运行前提与结果。
- 仅在影响理解或运行时简要注明版本差异；安装、依赖与配置保留必要版本。
- 引用外部资料时，在相关讲解附近提供具体页面或章节链接。

## API 与框架案例

目标为「会用」及以上时，案例说明：

- **用途与前提**：解决什么问题，所需依赖、import，以及对象来自构造、工厂、注入还是自动配置。
- **调用与结果**：具体输入、完整调用、返回值或状态变化，以及理解案例必需的局部语法；依赖工程上下文时给出文件位置与运行入口。
- **机制与边界**：关键执行时序、异常与失败条件及观察方式。框架隐式行为说明由谁、何时完成，依赖什么条件。

## 课件问答与答案

围绕用途、输出预测、执行顺序和关键原理设置问答，题目与解析保存在对应教材章节。每题附结论和理由；开放题提供判断标准与合理答案范围。问题使用稳定锚点供目录和课堂定位。

## 模板使用

- 以 [HTML 模板](../assets/lesson-example.html) 和 [配套样式](../assets/lesson-example.css) 为基础，替换示例内容与导航；先复用已有资源，首次生成时将模板样式保存为共享资源目录中的 `lessons.css`。
- 页面可直接打开，资源与跨页导航使用相对链接。教材根目录内的页面引用 `assets/lessons.css`，章节子目录内的页面引用 `../assets/lessons.css`；分享或迁移时携带本地依赖。
- 课件及生成的共享资源在文件注释中记录 `programming-teacher` 与当前版本。

## 本地 HTTP 预览与自动刷新

用户需要预览时优先复用已有脚本或服务，核实服务根目录、端口和目标页面。新服务绑定 `127.0.0.1`，根目录覆盖教材及资源；默认在课程根目录执行：

```powershell
npx live-server .learning/lessons --host=127.0.0.1 --port=5500 --no-browser
```

使用本机 Node.js/npm，已有安装优先复用；首次 `npx` 可能下载依赖。[live-server](https://github.com/tapio/live-server#usage-from-command-line) 支持保存后自动刷新。

无法使用自动刷新工具时，可用本机 Python 3（Windows 也可用 `py`）：

```powershell
python -m http.server 5500 --bind 127.0.0.1 --directory .learning/lessons
```

此方式需手动刷新。端口占用时换用空闲端口，启动后检查目标页面响应，提供实际页面与章节链接，说明刷新方式。保留服务进程或会话标识，复用时重新检查状态，仅停止本任务启动的服务。无法启动时提供文件链接及适用命令。
