# 从数据到函数

变量为数据命名，表达式产生计算结果，函数将一组操作组织为可重复调用的行为。这一章用商品金额计算贯穿这些概念。

## 阅读顺序

1. [变量与表达式](./01-variables.md)：保存输入，计算结果。
2. [函数与返回值](./02-functions.md)：把计算写成可复用的函数。
3. [作用域](./03-scope.md)：理解变量的可见范围。

## 阅读目标

- 区分变量、表达式与函数调用。
- 追踪实参、形参和返回值之间的关系。
- 根据声明位置判断变量是否可访问。

## 案例环境

示例为独立的 JavaScript 代码片段，可在浏览器开发者工具的控制台观察结果。同名函数的不同版本分别展示，不需要合并成一个程序。
