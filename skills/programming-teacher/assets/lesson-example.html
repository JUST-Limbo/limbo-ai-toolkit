阶段一 · 语言基础

函数与返回值

函数将一组操作封装为可重复调用的行为。通过参数传入数据，通过返回值取得计算结果，是组织程序逻辑的基本方式。

先修
变量、数字运算、条件判断
目标
解释调用过程，编写带返回值的函数
环境
现代浏览器的 JavaScript 控制台

01从一个计算需求开始

计算商品总价需要单价和数量。将计算过程写成函数，同一种计算就可以用于不同商品。

function 声明函数，calculateTotal 是函数名。圆括号声明输入参数，大括号包含调用时执行的语句。

  1. 声明函数时建立函数定义。
  2. 执行 calculateTotal(20, 3) 时，将输入传入函数并执行函数体。
  3. return 将计算得到的 60 返回给调用处，再赋给变量 total。

定义与执行：函数声明保存行为；函数调用才执行函数体。同一函数可以用不同输入多次调用。

02参数如何进入函数

声明中的 price 和 quantity 是形参，调用中的 20 和 3 是实参。普通位置参数按照出现顺序对应。

calculateTotal(20, 3) 的参数对应关系
位置形参本次调用的值含义
第一个price20单价
第二个quantity3数量

缺少参数时的结果

本例没有传入数量，quantity 的值是 undefined。数字与 undefined 相乘得到 NaN，表示此次数值计算未得到有效数字。此函数约定调用方提供两个有效数字。

03返回结果与打印结果

return 把值交给调用方，并结束本次函数执行；console.log 把信息显示在控制台。打印出的内容与函数返回值是两个不同的结果。

showTotal 执行后打印 60，但没有显式返回结果，调用得到的返回值是 undefined。需要继续计算时，应使用返回数值的 calculateTotal。

提前返回可以处理特殊条件

数量为零时，第一个 return 结束调用，后面的乘法不会执行。其他输入继续执行最后一行。

04理解检查

问题一 · 预测结果

const amount = calculateTotal(12, 4); 执行后，amount 是什么？计算过程中，两个实参分别对应哪个形参？

请先作答，再展开参考答案对照。

展开参考答案

amount 是 48。实参 12 对应 price，实参 4 对应 quantity，函数将乘积返回给调用方。

问题二 · 解释行为

showTotal 已经打印了总价，为什么赋值给 result 后仍得到 undefined？应如何让调用方取得总价？

请先作答，再展开参考答案对照。

展开参考答案

打印只产生控制台输出。函数没有显式返回总价，因此调用结果是 undefined。将函数体改为 return price * quantity;，调用方即可取得并继续使用这个数值。

问题三 · 追踪执行路径

在“提前返回”的版本中，调用 calculateTotal(20, 0) 时执行了哪个 return？最后一行会执行吗？

请先作答，再展开参考答案对照。

展开参考答案

条件 quantity === 0 成立，执行分支内的 return 0;，返回 0 并结束调用。最后一行不会执行。

05小结与资料

  • 定义：用函数名、参数和函数体描述可重复执行的行为。
  • 调用：实参按位置传入，本次调用执行函数体。
  • 返回：return 提供调用结果并结束执行；控制台打印用于观察。
